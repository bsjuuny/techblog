# David Baek's Tech Blog

16년 이상 웹 프론트엔드와 UI 개발을 해온 David Baek의 기술 블로그입니다.
React, TypeScript, 엔터프라이즈 UI, 웹표준, 웹접근성, 반응형 UI 경험을 기록합니다.

## 바로가기

- [기술 블로그](https://bsjuuny.github.io/techblog/)
- [경력 및 프로젝트 소개](https://bsjuuny.github.io/techblog/about/)

## 주요 주제

- React / TypeScript 기반 프론트엔드 아키텍처
- 관리자·백오피스·금융권 업무 UI
- REST API / GraphQL 연동과 화면 상태 설계
- 웹표준·웹접근성·반응형 UI
- Vue·Angular·jQuery 레거시 운영 및 전환

## 기술 구성

- Jekyll
- Minimal Mistakes
- GitHub Pages

## 로컬 실행

```bash
bundle install
bundle exec jekyll serve
```

로컬 서버 실행 후 `http://localhost:4000/techblog/`에서 확인할 수 있습니다.
