# 오늘의 기술 뉴스 브리핑

오늘은 플랫폼 권력이 개발자와 오픈소스 생태계를 어떻게 옥죄는지 보여주는 두 사건이 눈에 띕니다. 여기에 CSS로 물리 기반 조명을 흉내내는 실험적 프로젝트, 로컬 LLM 최적화 이야기, 그리고 저사양 하드웨어에서 초거대 모델을 굴리는 시도까지 더해 개발자가 챙겨볼 만한 소식들을 모아봤습니다.

## Google Play, AuroraStore를 막다

Aurora Store는 Google Play 계정 없이도 Play 스토어의 앱을 받을 수 있게 해주는 오픈소스 클라이언트로, GrapheneOS 같은 프라이버시 중심 커스텀 안드로이드 배포판 사용자들에게는 거의 필수 도구입니다. 기사 설명에 따르면 현재 최신 Nightly 빌드조차 "서버가 바쁘니 나중에 다시 시도하라"는 오류를 반환하며 정상 작동하지 않는 상황입니다.
구글이 직접 차단을 공표한 건 아니지만, 앱스토어 운영사가 우회 클라이언트의 API 접근을 조용히 틀어막는 방식은 과거에도 여러 번 있었던 패턴입니다.
플랫폼에 종속되지 않는 소프트웨어 배포 채널을 만드는 게 왜 계속 취약한 구조인지, 그리고 이런 서드파티 클라이언트를 만드는 개발자라면 API 변화에 얼마나 취약한 위치에 있는지 다시 생각하게 하는 사건입니다.

## AnkiDroid 후원 링크, Google Play가 막다

AnkiDroid는 유명한 오픈소스 플래시카드 학습 앱인데, Google Play가 Open Collective를 통한 기부 링크를 더 이상 허용하지 않는다고 통보한 모양입니다. 이슈에는 구글 티켓 번호까지 명시되어 있고, 핵심 쟁점은 "IRS 501(c)(6) 비영리 인증이 '세금 면제 기부' 조건을 만족하는지"에 대한 명확한 답을 구글로부터 받지 못하고 있다는 점입니다.
오픈소스 프로젝트가 스토어 정책상 결제/기부 수단으로 어떤 법적 지위를 요구받는지가 애매하게 처리되면, 결국 개발자가 시간을 들여 법률 용어와 씨름해야 하는 상황이 됩니다.
개인이나 소규모 팀이 유지하는 인기 오픈소스 앱일수록 이런 정책 리스크에 노출되기 쉽고, 실제로 후원금이 끊기면 프로젝트 지속 가능성 자체가 흔들릴 수 있다는 점에서 단순한 "정책 디테일" 이상의 문제입니다.

## Ambient CSS v3 – 블렌더식 조명을 CSS로

box-shadow만으로 빛의 방향, 그림자, 하이라이트, 표면 그라디언트를 계산해내는 프로젝트로, Blender의 레이트레이싱 결과를 기준으로 보정했다는 설명이 흥미롭습니다. 하나의 광원 위치를 정의하면 그에 따라 모든 그림자와 광택이 자동으로 계산된다는 아이디어 자체가 CSS로 조명 시스템을 시뮬레이션하려는 시도입니다.
디자인 시스템에서 일관된 "빛의 방향성"을 유지하고 싶은 UI 개발자에게는 매력적인 도구가 될 수 있습니다.
다만 실제 성능이나 브라우저 호환성, 세부 API 사용법은 헤드라인만으로는 알 수 없으니 자세한 내용은 원문을 참고하는 게 좋습니다.

## 작은 트랜스포머로 LLM을 이기다?

"1.5시간 학습시킨 소형 트랜스포머가 여러 LLM을 능가한다"는 주장인데, 어떤 벤치마크와 조건에서인지는 헤드라인만으로는 알 수 없습니다. ARC 관련 실험으로 보이지만 구체적인 모델 크기, 데이터, 비교 대상 LLM 목록은 자세한 내용을 원문에서 확인해야 합니다.
그럼에도 이런 종류의 글이 항상 흥미를 끄는 이유는, "무작정 크게 만들면 된다"는 스케일링 신화에 반례를 제시하는 시도이기 때문입니다.
과제 특화 소형 모델이 범용 대형 모델을 특정 태스크에서 이기는 사례는 실무에서 비용 대비 효율을 고민하는 엔지니어에게 항상 참고할 가치가 있습니다.

## 48GB 맥에서 104GB 모델 돌리기

Qwen3.8-Flash-Next라는 125B MoE 모델(4비트 양자화 시 104GB)을 48GB 메모리의 맥에서 SSD로 전문가(expert) 가중치를 스트리밍하며 초당 약 12토큰으로 구동했다는 프로젝트입니다. MoE 구조는 추론 시 전체 파라미터가 아니라 일부 전문가만 활성화되는데, 이 특성을 이용해 필요한 전문가만 그때그때 SSD에서 불러오는 방식으로 메모리 제약을 우회한 셈입니다.
MLX와 Swift 기반으로 Ollama 호환 API를 제공한다는 점도 실제로 써보기 쉽게 만든 부분입니다.
로컬 LLM을 돌리고 싶지만 메모리가 부족한 개발자들에게는 속도는 느려도 "돌릴 수 있다"는 것 자체가 의미 있는 선택지가 될 수 있습니다.
